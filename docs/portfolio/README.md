Everything needed to present the demo on the KHENOV portfolio. **Every text and image must say it is a demo with fictional data.** Never describe it as a client project, never show real names, and never add testimonials or metrics.

| File                             | What it is                                                  |
| -------------------------------- | ----------------------------------------------------------- |
| [COVER.md](COVER.md)             | Cover image specification and how to produce it             |
| [SCREENSHOTS.md](SCREENSHOTS.md) | Shot list (6 screenshots) with exact steps                  |
| [VIDEO.md](VIDEO.md)             | 30-second video script, recording tips, compression command |
| [SUMMARY.md](SUMMARY.md)         | Project summary in Arabic and English, card line, tags      |
| [card.json](card.json)           | Portfolio card data (links are placeholders)                |

Media files go next to the card, in `docs/portfolio/media/` (not committed; keep the originals outside git). File names are fixed in `card.json`.

Before publishing: replace `<LIVE_DEMO_URL>` and `<DOWNLOAD_URL>` in `card.json`, swap the placeholder app icon for the official KHENOV mark (see [../BUILD-WINDOWS.md](../BUILD-WINDOWS.md)), and check that every screenshot shows the "Demo by KHENOV" badge.
